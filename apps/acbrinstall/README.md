# ACBrInstall

Aplicativo de instalação de componentes ACBr em uma IDE existente.
Lazarus: Linux, Windows e macOS. Delphi: somente Windows.

```bash
cargo run -p acbrinstall
cargo run -p acbrinstall -- --help
```

O backend não instala FPC/Lazarus: essa tarefa pertence ao PascalInstall.
Consulte o [guia do workspace](../../README.md).
