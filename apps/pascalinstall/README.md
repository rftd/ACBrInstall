# PascalInstall

Aplicativo para preparar FPC, Lazarus, cross-compilers, OPM e designer integrado.
Linux, Windows e macOS (Intel e Apple Silicon).

```bash
cargo run -p pascalinstall
cargo run -p pascalinstall -- --help
```

O backend não acessa fontes nem instala componentes ACBr.
Consulte o [guia do workspace](../../README.md).
