# Ícones dos aplicativos

`acbrinstall.ico` e `acbrinstall.icns` foram copiados do instalador Delphi
original do Projeto ACBr, em
`Projetos/ACBrInstall Trunk2/ACBrInstall_Trunk2.Artwork/Windows/AppIcon.ico`
e do respectivo recurso macOS. A identidade visual pertence ao Projeto ACBr.
`acbrinstall.png` foi extraído do frame de 256×256 do ICO, preservando o alfa.

`pascalinstall.png` é o original gerado por IA usando a ferramenta ImageGen,
com fundo transparente. `pascalinstall-256.png`, `.ico` e `.icns` são conversões
e redimensionamentos desse original com Pillow. O ICO inclui tamanhos de 16 a
256 pixels. A interface usa o PNG de 256 pixels; Windows usa ICO e macOS usa ICNS.

Prompt usado na geração:

```text
Use case: logo-brand. Asset type: desktop application icon for PascalInstall, the separate installer for Free Pascal and Lazarus on Linux, Windows and macOS. Create one polished square app icon, 1024 by 1024. A bold, highly readable white uppercase letter P forms the main mark on a deep navy and royal-blue rounded-square tile. Integrate a simple cyan downward installation arrow at the lower right as part of the same coherent mark. The visual identity should suit a programming tool and the existing blue installer interface. Clean geometric shapes, restrained dimensional depth, crisp silhouette, generous simple forms that remain clear at 16, 32 and 64 pixels. Center the icon with even small padding. Actual transparent background outside the rounded tile, preserve alpha. No full product name, no other lettering, no watermark, no mockup, no extra objects, no collage.
```
